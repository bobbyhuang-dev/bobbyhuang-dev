WallpaperMachine
https://github.com/WallpaperMachine/WallpaperMachine

A native macOS app that plays Wallpaper Engine scene, video and web wallpapers live on your desktop. Steam Workshop browsing and downloads are built in through SteamCMD, so no Windows program ever runs. Every display gets its own wallpaper with its own scaling, frame rate and volume. Free signed build, GPL-2.0 source.
